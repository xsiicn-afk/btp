# Макет этикетки ByTop v1.0

## Назначение

Этикетка предназначена для наклеивания на системный блок.

Версия 1.0 рассчитана на печать:

- Xerox Phaser 3160
- лист A4
- 4 этикетки на листе

Размер одной этикетки:

105 × 148 мм (A6)
