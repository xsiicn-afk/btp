# ByTop Production Suite

## Назначение

Программа предназначена для автоматизации подготовки документов при сборке ПК.

Источник данных — текст спецификации из 1С.

Из одной конфигурации автоматически формируются:

- модель системного блока
- этикетка
- паспорт изделия
- журнал
- PDF

---

# Поток данных

1С
↓
BasicParser
↓
Configuration
↓
ModelBuilder
↓
LabelModel
↓
Preview / PDF / Print

---

# Основные объекты

## Configuration

Хранит полную конфигурацию компьютера.

Никакие строки не сокращаются.

Используется для:

- журнала
- повторной печати
- паспорта
- редактирования

---

## LabelModel

Хранит только данные, необходимые для печати.

Например:

Название модели

Процессор

Память

Накопители

Видео

Форм-фактор

Блок питания

Серийный номер

---

## BasicParser

Разбирает текст из 1С.

Не занимается сокращениями.

Только определяет категории комплектующих.

---

## ModelBuilder

Формирует коммерческое название модели.

Пример:

Core i5-12400F

DDR5 64GB 5600MHz (2×32)

SSD NVMe 4TB

RTX5070 12GB

mATX

1200W

---

## PreviewWidget

Не знает о структуре комплектующих.

Получает готовый LabelModel.

Отображает его.

---

# Правило проекта

Configuration — источник истины.

LabelModel можно изменять вручную.

Configuration всегда хранит оригинальные данные.
